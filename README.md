# 📈 Projetos Realizados

## 💰 S.A.N.E - Sistema de Apoio a Negócios e Empresas

O **S.A.N.E** é um sistema digital desenvolvido para **MEIs e MEs**, criado para enfrentar problemas como:

* Má gestão empresarial
* Falta de planejamento estratégico
* Controle financeiro precário

---

### ⚙️ O sistema integra

📊 **Cálculo automático de tributos**

📍 **Pesquisa de mercado com geolocalização**

🤖 **Relatórios gerados por IA**

🛍 **Catálogo de produtos e serviços**

---

Foi desenvolvido utilizando **APIs e uma interface intuitiva**, com o objetivo de promover **inclusão produtiva e apoio estratégico para pequenos negócios**.
